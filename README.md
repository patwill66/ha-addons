# Home Assistant add-ons

A personal Home Assistant add-on repository. To add it: Settings → Apps → App Store → ⋮ → Repositories,
then `https://github.com/patwill66/ha-addons`.

| Add-on | What it does |
|---|---|
| [Mammotion Collector](mammotion_collector/DOCS.md) | Logs a Mammotion LUBA mower's history to SQLite through the official Mammotion Developer API (read-only, no control commands) |
| [eero Collector](eero_collector/DOCS.md) | Keeps an eero mesh network's history (clients, Wi-Fi quality, usage, mesh health) in SQLite and publishes it to Home Assistant over MQTT (read-only, never changes the network) |

Both add-ons are generated by publish scripts from private repositories; don't edit them here.
